# Enterprise ERP 2.0 — Full Program Plan (automation source)

**Baseline:** `pilot-v1.1.0` (Pilot COMPLETE)  
**Target:** `enterprise-2.0.0` (GA without compromises)  
**Automation:** `scripts/enterprise-2.0/run-automation.sh` + agent prompts

This document is the human-readable program. Machine control plane: `docs/enterprise-2.0/milestones.json` + `docs/ENTERPRISE-2.0-STATUS.md`.

---

## Non-negotiables

1. Auth always ON; iss/aud; no X-Dev-Role; no implicit OIDC in prod  
2. JetStream mandatory on enterprise path; no silent core-NATS  
3. Outbox TX + multi-replica safe claim  
4. Idempotent consumers  
5. No secrets in git tree; history Variant B unless A approved  
6. Tenancy: **DEDICATED_STACK** (default) or SHARED_RLS if STATUS changed  
7. Decimal money; migrate-only in prod  
8. Gates = live chaos + e2e + build — **never** readiness theater  
9. No Faza 29+ pipelines

---

## Phase semantics (automation)

| Phase | Who | What |
|-------|-----|------|
| **DESIGN** | Grok `/design` or agent with design persona | Write design + PR Plan to `design_doc` |
| **IMPLEMENT** | Grok `/execute-plan` or implement agent | Implement PR plan on milestone branch |
| **GATE** | `gate-check.sh` + live smokes | Fail closed; re-enter IMPLEMENT on fail |
| **RELEASE** | `gh pr` + tag | Merge to master; tag; advance milestone |

---

## How automation runs

```bash
# One step (safe)
pnpm run enterprise:step

# Continuous loop (until BLOCKED/DONE or max iterations)
pnpm run enterprise:loop

# Emit next Grok prompt only
pnpm run enterprise:prompt

# Run gates for current milestone
pnpm run enterprise:gate
```

**Grok continuous mode:** paste `docs/enterprise-2.0/NEXT_AGENT_PROMPT.md` (regenerated by runner) into Grok; agent executes, updates STATUS, pushes; scheduler resumes every N hours with RESUME prompt.
